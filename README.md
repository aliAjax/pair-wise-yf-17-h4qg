# 管风琴维护台 · 音管调音与检修

给管风琴维护人员使用的本地工作台。内置两厅堂、三音栓、八支音管，记录每支音管的
锡 / 铅 / 木材质、实测音高、实测气温、湿度、簧片状况与检修备注。

## 业务规则

- 提交结论时按**材质温漂**折算 20℃ 偏差：
  `20℃偏差 = 实测偏差(音分) − (实测气温 − 20) × 材质系数`
  （锡管 2.6、铅管 1.8、木管 1.2 音分/℃），|折算偏差| ≤ 15 音分为**通过**。
- 资料不齐（材质 / 实测音高 / 气温 / 湿度缺失）或气温不在 **5–35℃** 窗口：
  不折算、不判定，只**留待复核**。
- 结论**锁定后不可变**：再调整材质、气温或实测音高，只让相关音管**退出当前通过**，
  历史结论文字、测值快照、时间均保留不动（以 `材质|气温|测值` 指纹比对）。
- 偏差表、异常表、环境记录、维护单共用同一份 **localStorage 本地存档**。

## 三个业务模块

| 层 | 目录 | 职责 |
| --- | --- | --- |
| 判定 | `src/domain/` | 温漂折算、复核门限、异常识别、结论指纹与退出逻辑（纯函数） |
| 数据 | `src/archive/` | 存档类型、种子资料（两厅堂/三音栓/八音管）、localStorage store |
| 展示 | `src/ui/` + `src/App.tsx` | 音管总览、偏差表、异常表、环境记录、维护单、结论档案六个视图 |

## 页面

- **音管总览**：按厅堂 / 音栓分组的八音管卡片，可直接改材质、温湿度、测值、簧片与备注，单管提交结论。
- **偏差表**：实测偏差、温漂修正、20℃折算偏差与当前判定，支持勾选批量锁定。
- **异常表**：待复核、超限、簧片异常、木管湿度警戒、锁定后退出通过的汇总。
- **环境记录**：按厅堂追加温湿度记录，气温越窗标红。
- **维护单**：按异常自动开单，维护建议、单据状态与处理记录独立保存。
- **结论档案**：只追加的锁定历史，标注「已退出通过（历史不动）」。
