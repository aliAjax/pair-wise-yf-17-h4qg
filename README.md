# hxyfront-62005 管风琴音管调音记录

给管风琴维护人员使用的音管调音与维护工作台：内置两个厅堂、三组音栓、八支音管，
逐管记录锡 / 铅 / 木材质、实测音高、温湿度、簧片状况与检修备注。

## 判定规则

- **二十摄氏度折算**：提交结论时按材质线膨胀系数一阶折算
  `f₂₀ = f测 × (1 + α(20 − t))`，再以 `1200 × log₂(f₂₀ / f₀)` 计算音分偏差；
  `|偏差| ≤ 5` 音分为**通过**，否则**不通过**。
  - 锡（锡基合金）α = 2.3e-5 /℃；铅（铅基合金）α = 2.9e-5 /℃；木 α = 0.5e-5 /℃。
- **只留待复核**：实测音高 / 气温 / 湿度任一缺失（资料不齐），或气温不在 **5–35℃**
  区间时，不做温漂折算，判定一律为待复核。
- **簧片异常**（磨损 / 变形）单独登记进异常表，不改变偏差判定。
- **结论锁定**：点击「提交结论并锁定本批」生成批次号（B001、B002…），
  偏差表、异常表、环境记录、维护单一并固化进本地存档，历史只读。
- **锁定后退出通过**：锁定后再调整材质、气温或实测音高，只让相关音管退出其历史
  通过结论（异常表与退出记录追加条目）；历史偏差表与批次统计一律不动。
  改检修备注、簧片状况等非判定字段不影响通过；同批次同管只记一次退出。

## 模块划分

| 业务层 | 位置 | 职责 |
| --- | --- | --- |
| 判定 | `src/modules/judge.ts` | 纯函数：温漂折算、音分偏差、通过 / 不通过 / 待复核 |
| 数据 | `src/modules/archive.ts` | 本地存档（localStorage）：偏差表 / 异常表 / 环境记录 / 维护单共用一份，批次快照不可变，退出通过只追加 |
| 展示 | `src/components/*`、`src/App.tsx` | 音管录入、偏差表、异常表、环境记录、维护单五个视图 |

类型定义见 `src/types.ts`，初始档案见 `src/data/seed.ts`。

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式）

## 本地运行

```bash
npm install
npm run dev        # 开发服务器，端口 62005
npm run build      # 类型检查 + 生产构建
npm run check      # 判定 / 锁定 / 退出通过 规则的逻辑自测
```

开发端口：62005

页面内「清空本地存档」可删除全部 localStorage 数据并恢复八支音管初始档案。
